# StudyMind Frontend

A polished frontend prototype for the NEXUS 2026 Smart Document Knowledge Assistant.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Current scope

- Dashboard
- Document upload UI for PDF/TXT
- AI chat interface
- Source/evidence panel
- Interactive quiz
- Flashcards
- Learning insights
- Responsive layout
- Light/dark appearance toggle

## Backend integration planned

Connect the UI to a Python/FastAPI backend for PDF/TXT extraction, chunking, embeddings, vector retrieval, RAG generation, real citations, and persistent learning analytics.
